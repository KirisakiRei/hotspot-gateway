# ============================================
# MIKROTIK HOTSPOT PRODUCTION SETUP
# ============================================

## 1. WALLED GARDEN - Allow Portal Access Before Login
# Ganti IP_SERVER dengan IP laptop Anda (misal: 192.168.88.2)

/ip hotspot walled-garden
add dst-host=192.168.88.2 comment="Portal Website"
add dst-host=localhost comment="Local access"

# Jika pakai domain
add dst-host=hotspot.local comment="Portal Domain"


## 2. HOTSPOT SERVER PROFILE - Custom Login Page
# Edit profile hotspot yang aktif (biasanya "hsprof1")

/ip hotspot profile
set hsprof1 login-by=http-chap,cookie,mac-cookie \
  html-directory=hotspot \
  http-cookie-lifetime=1d \
  trial-uptime-limit=none

# Set custom login page URL
set hsprof1 html-directory-override="http://192.168.88.2:5173/portal"


## 3. CUSTOM LOGIN PAGE (Alternative Method)
# Redirect langsung ke portal Anda

/ip hotspot profile
set hsprof1 login-by=http-chap \
  http-cookie-lifetime=1d

# Setelah itu, edit file login.html di Mikrotik:
# Files > hotspot > login.html
# Ganti dengan redirect ke portal Anda


## 4. NETWORK CONFIGURATION
# Pastikan laptop bisa diakses dari network hotspot

# Cek IP laptop Anda di network hotspot
# Jalankan di CMD/PowerShell laptop:
# ipconfig

# Biasanya IP hotspot network: 192.168.88.x


## 5. FIREWALL - Allow Portal Traffic

/ip firewall filter
add chain=input protocol=tcp dst-port=3001 action=accept comment="Backend API"
add chain=input protocol=tcp dst-port=5173 action=accept comment="Frontend Portal"


## 6. DNS - Setup Local Domain (Optional)

/ip dns static
add name=hotspot.local address=192.168.88.2 comment="Portal Website"

## ============================================
## TROUBLESHOOTING
## ============================================

### Portal tidak bisa diakses:
- Cek Windows Firewall di laptop (allow port 3001 & 5173)
- Cek IP laptop: ipconfig
- Test dari device lain: ping 192.168.88.2

### Mikrotik tidak redirect:
- Cek hotspot server status: /ip hotspot print
- Cek walled garden: /ip hotspot walled-garden print
- Restart hotspot server: /ip hotspot disable 0; /ip hotspot enable 0

### MAC/IP masih null:
- Cek URL saat redirect, harus ada parameter: ?mac=...&ip=...
- Jika tidak ada, cek hotspot profile configuration


## ============================================
## WINDOWS FIREWALL SETUP
## ============================================

# Jalankan di PowerShell as Administrator:

# Allow Backend Port
New-NetFirewallRule -DisplayName "Hotspot Backend API" -Direction Inbound -LocalPort 3001 -Protocol TCP -Action Allow

# Allow Frontend Port
New-NetFirewallRule -DisplayName "Hotspot Frontend Portal" -Direction Inbound -LocalPort 5173 -Protocol TCP -Action Allow

# Check firewall rules
Get-NetFirewallRule | Where-Object {$_.DisplayName -like "*Hotspot*"}


## ============================================
## PRODUCTION DEPLOYMENT (Cloud/VPS)
## ============================================

For production server (bukan laptop):

1. Deploy Backend to Cloud (Railway, Heroku, DigitalOcean)
2. Deploy Frontend to Vercel/Netlify
3. Update Mikrotik walled garden dengan domain production
4. Update environment variables:
   - FRONTEND_URL
   - MIKROTIK_HOST (IP public atau VPN)
5. Setup SSL certificate (Let's Encrypt)


## ============================================
## CUSTOM MIKROTIK LOGIN PAGE
## ============================================

Option 1: Direct Redirect (Recommended)
- Edit Mikrotik Files > hotspot > login.html
- Add redirect script:

<!DOCTYPE html>
<html>
<head>
    <title>Redirecting...</title>
    <script>
        window.location.href = 'http://192.168.88.2:5173/portal?' + window.location.search;
    </script>
</head>
<body>
    <p>Redirecting to portal...</p>
</body>
</html>

Option 2: Use html-directory-override
- Set in hotspot profile
- Points directly to your portal URL


## ============================================
## BACKEND CONNECTION TO MIKROTIK
## ============================================

Pastikan Backend bisa connect ke Mikrotik:

1. Buka Admin Panel: http://192.168.88.2:5173/admin
2. Login dengan admin credentials
3. Go to Settings > Mikrotik
4. Fill:
   - Host: 192.168.88.1 (IP Mikrotik)
   - Port: 8728
   - Username: admin
   - Password: (your mikrotik password)
5. Click Test Connection
6. Save settings

Test di Router page:
- Should show "Connected" status
- Can view hotspot users
- Can view profiles
- Monitoring dashboard shows live data
